## 1. TL;DR

カプコンは 2026 年 10 月 22 日、共通アカウント「CAPCOM ID」に第三者による不正アクセスがあり、メールアドレスとシステム固有の識別情報が全世界で 11,774,247 件漏えいしたと公表した。うち 196 件では、ログインのパスワードが不正に変えられていた。翌 23 日の第二報で、その 196 件のうち 19 件では、同じ ID で入る通販サイト「イーカプコン」のマイページに第三者が入り、氏名、住所、電話番号、購入履歴などが漏えいしたと公表した。

カプコンは、会員が自分で設定したパスワードの漏えいは確認されていないとしている。それでもパスワードは変えられ、変えた後のパスワードで通販のマイページに入られた。どのように変えられたかは公表されていない。

カプコンは 10 月 19 日に痕跡を見つけて遮断し、攻撃の手段を特定して対応したと公表している。ただ、196 件のパスワードの変更は通っていた。効かなかったのは、パスワードの変更が持ち主の操作かを、確定の前に照合する層である。

## 2. 何が起きたか

- **サービス**: CAPCOM ID は、カプコンの Web サービスや一部のオンラインゲームで使う、登録制の共通アカウント（カプコン）。カプコンの通販サイト「イーカプコン」も、利用には CAPCOM ID の登録が要る（イーカプコンのご利用ガイド）。
- **漏えいした情報**: メールアドレスとシステム固有の識別情報（アカウントの作成日時、最終ログイン日時、ログイン回数、最終ログイン時の接続元 IP アドレス）が、全世界で 11,774,247 件。うち 43 件では、生年月日、性別、国・地域、ニックネームも漏えいした。クレジットカードの情報は含まれない（カプコン第一報）。
- **パスワードの不正な変更**: 11,774,247 件のうち 196 件で、ログインのパスワードが不正に変えられていた。会員が自分で設定したパスワードの漏えいは確認されていない。196 件はパスワードをリセットした（カプコン第一報）。
- **通販のマイページ**: 196 件のうち 19 件（日本国内）で、第三者がイーカプコンのマイページに不正に入り、氏名、氏名（カナ）、電話番号、郵便番号、住所、性別、生年月日、購入履歴、イーカプコンへの問い合わせ履歴、会員の住所録が漏えいした。ほかのアカウントでは、パスワードの変更による漏えいは確認されなかった（カプコン第二報）。
- **経路**: カプコンは、攻撃の手段を特定して対応を完了したとしている。手段の中身は公表されていない（カプコン第一報）。
- **公表されていないこと**: どこから入られたか、侵入が始まった日、パスワードがどの手順で変えられたか（再設定の手順か、ほかの機能か）、変更が持ち主に知らされたか、多要素認証の有無、なぜ 196 件だったか。

## 3. 時系列 — 公表と対応

- **2026-10-19**: カプコンが CAPCOM ID への不正アクセスの疑いのある痕跡を見つけ、直ちにそのアクセスを遮断して調べ始める。同日、不正アクセスがあったことを確かめ、緊急の対策と、攻撃の手段の特定を始める。
- **2026-10-20**: 社内に対策本部を置く。登録された情報の一部の漏えいと、一部のアカウントでのパスワードの不正な変更が分かる。外部の助言組織であるセキュリティ監督委員会に報告する。
- **2026-10-21**: 警察と個人情報保護委員会に報告する。
- **2026-10-22**: 第一報を公表する（適時開示）。緊急の対策と、攻撃の手段の特定と対応を完了したとし、CAPCOM ID を使うサービスは引き続き使えるとした。
- **2026-10-23**: 第二報で、パスワードを変えられた 196 件のうち 19 件で、イーカプコンのマイページに入られたと公表する。影響範囲の調査は完了したとした。

> 事実はカプコンの第一報と第二報（いずれも一次・適時開示、同社サイトに日本語と英語）に拠る。第一報は、攻撃の手段を「特定と対応を完了」と書くが、中身は書いていない。10 月 26 日時点で、第三報は出ていない。

### 公表後の対応

- **カプコン**: 196 件のパスワードをリセットし、対象の会員に順次知らせている。専用の問い合わせ窓口を国内外に置いた。CAPCOM ID と関連サービスの監視を続け、原因を踏まえた再発防止策を講じるとしている。
- **会員への注意**: 漏れた情報を使って、カプコンや関係先を装うメール、ショートメッセージ、電話が来るおそれがあるとして、URL や添付ファイルを開かないよう呼びかけている。

## 4. なぜ止まらなかったか

この事案の失敗は、メールアドレスが漏れたことだけではない。**パスワードの変更を、持ち主の操作かと照合してから確定する層**が、公表からは見えないことにある。

検出は働き、カプコンは痕跡を見つけた日に遮断し、変えられたパスワードをリセットした。ただ、「パスワードを変える操作が届いた」と「この変更は、このアカウントの持ち主が行った」は別々の事実で、公表からは、前者を後者と照合してから確定する層は見えない。共通アカウントでは、一つの変更が、住所や購入履歴を持つほかのサービスへの入口にもなる。この隔たりが**検出と証明の落差**であり、構造的な欠落である。

同じ構造は、[Instagram のサポート経由の乗っ取り](https://lemma.frame00.com/ja/critical/briefs/051-instagram-ai-support-takeover/)（持ち主かを確かめないまま、アカウントのメールアドレスが変えられた）にも現れている。

## 5. 対策するには

**パスワードやメールアドレスの変更は、そのアカウントの持ち主が行ったかを照合してから確定する。** そうすれば、どこから入られても、変更だけでは乗っ取りにならない。共通アカウントでは、照合できない変更の直後に、住所や購入履歴を持つサービスへ入れないようにする。検出の代わりではなく、検出の手前に置く層である。

### 注意したい業界・業務

- **業界 · メディア・コンテンツ**: ゲームや動画、電子書籍など、一つの会員アカウントで複数のサービスやアプリに入れる事業者。会員の数が多く、アカウントの変更は自動の手順で処理されることが多い。
- **業界 · サービス・小売**: 会員のアカウントで、住所や電話番号、購入履歴、配送先の住所録を持つ通販サイト。共通 ID でログインさせていると、ID の側の変更がそのまま通販の入口になる。
- **業務 · アカウント・権限の管理**: 会員のパスワードやメールアドレスの変更、再設定の手順の管理。

### いまの対策で防げるか

| 対策 | 今回 | 理由 |
| --- | --- | --- |
| パスワードを強くする・使い回さない | 関係しない | 会員が設定したパスワードの漏えいは確認されていない。パスワードは変えられた。 |
| 会員の多要素認証 | 一部 | ログインには効く。パスワードの変更や再設定の手順でも求めているかは、公表からは分からない。 |
| 不正アクセスの検知と遮断 | 一部 | 痕跡を見つけた日に遮断した。パスワードの変更と通販のマイページへの侵入がいつ起きたかは、公表されていない。 |
| パスワードのリセット | 一部 | 変えられた 196 件は戻した。19 件の住所や購入履歴は、すでに漏えいしていた。 |

### 必要になるもの

1. **変更は、持ち主に確認してから確定する。** パスワードやメールアドレスの変更は、変更前の登録済みの連絡先で持ち主に確認してから確定する。どの手順から届いた変更でも、確定の手前は一か所にそろえる。
2. **確認できない変更の直後は、ほかのサービスへの入場を止める。** 共通アカウントでは、変更の直後に住所や購入履歴を持つサービスに入るとき、もう一度本人を確かめる。
3. **誰がどの経路で変えたかを残す。** どの手順から、どのアカウントのパスワードが変えられたかを、後から照合できる形、つまり証明として残す。

### 点検チェックリスト

会員のアカウントの変更について、組織で確かめる 3 項目

- 会員のパスワードやメールアドレスが変わったとき、変更前の登録済みの連絡先にも知らせが届くか。
- 共通 ID で入るサービスのうち、住所や購入履歴を見られるものは、パスワードの変更の直後に入るとき、もう一度本人を確認しているか。
- 短い間に多くのアカウントでパスワードが変わったとき、気づいて変更を止められるか。

注：攻撃者がデータベースや管理の機能を直接書き換えられる場合は、この照合を通らずにパスワードを変えられる。今回の 196 件の変更を、この仕組みで止められたとは言えない。メールアドレスなど 1,177 万件の漏えいも、この層では止まらない。攻撃の手段は特定済みだが公表されていない。続報で判明すれば、この Brief を改訂する。
