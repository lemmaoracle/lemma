## 1. 要点

宮城県山元町の職員が、2026 年 6〜7 月に他の職員の ID とパスワードで庁内の共有フォルダと職員の個人専用フォルダに入り、データを閲覧・削除した（町の公表）。他の職員の端末も無断で使い、深夜や休日に庁舎へ入っていた。

同じ職員は、手続きを経ずに公印（町長印）を押した契約書を請負業者 2 社に交付し、上司 2 名の印影を偽造して、うち 1 名の印影で未決裁の文書を決裁済みとして使った。印紙も偽造した。町は 10 月 16 日付で免職とし、管理監督の責任で課長級と班長を戒告とした。

<strong>印影と公印は、押した人が承認者であることを示さない。</strong>

## 2. 通った操作

- **通った操作**: 2 つある。1 つは、他の職員の ID とパスワードでの、共有フォルダと個人専用フォルダへのアクセス（データの閲覧・操作・削除）。もう 1 つは、公印と偽造した印影を押した文書の交付と使用で、公印を押した契約書が請負業者 2 社に渡り、未決裁の文書が決裁済みの文書として使われた（町の公表）。
- **受け付けた側に届くもの**: 一般に、共有フォルダには ID とパスワードだけが届き、端末の前に誰がいるかは届かない。契約書や決裁文書を受け取る側には、押された印影だけが届き、承認者本人が押したかは届かない。町の公表によれば、印影は偽造され、印紙も、貼られた書類から読み取って加工する方法で偽造された。
- **公表されていないこと**: 閲覧・削除されたデータの中身（個人情報を含むか）。削除されたデータが戻ったか。契約書を交付した相手と、契約の中身・金額。未決裁の文書の種類。どのように発覚したか。警察への届出や告発。動機。再発防止の具体的な手立て。

## 3. 実行前の照合

経路を問わず区別できる条件は、決裁済みの文書や公印を押した契約書を使う前に、その承認が承認者本人の記録と結びつくかを、紙の印影とは別の決裁の記録で照合することである。

- **誰が承認を出すか**: 承認者本人（決裁の権限を持つ人と、公印の管理者）。決裁と押印は、本人だけが持つ鍵（職員証のカードや生体）で署名した操作として記録に残す。印影は、その記録の写しにすぎない。
- **どこで照合するか**: 文書を交付する手順と、決裁済みの文書を次の手続きに使う手順。承認者本人の記録と結びつかなければ、交付と使用を保留する。共有フォルダへのアクセスも、ID の持ち主本人の鍵と照合して通す。他の職員の端末からでは、その鍵は使えない。
- **何が残るか**: 誰が、いつ、どの端末と ID で、どの文書を決裁・押印したかの記録。契約の相手への説明、処分、告発で、承認が本人のものだったかを示せる。

発覚の経緯は公表されていない。正規の権限や管理の口が本人の依頼なしに使われた事案に、[岩井コスモ証券](https://lemma.frame00.com/ja/critical/briefs/190-iwai-cosmo-tradeworks-admin-function-unintended-orders/)（委託先の管理機能からの注文）と [デンマーク CPR](https://lemma.frame00.com/ja/critical/briefs/152-denmark-cpr-lawful-access-misuse/)（正規の照会権限の悪用）がある。公的機関で、承認の有無が伝わらないまま手続きが進んだ事案に [ロンドン警視庁](https://lemma.frame00.com/ja/critical/briefs/157-met-police-auror-unapproved-platform/)（「承認済み」と誤って伝わった基盤）、自治体の住宅供給公社で送付物の宛名がずれた事案に [東京都住宅供給公社](https://lemma.frame00.com/ja/critical/briefs/134-tokyo-housing-supply-corp-label-misdirection/) がある。今回は、本人の認証を経ない ID の使用と、承認者を経ない印影の両方が通った。

## 4. Lemma でできること

**Lemma は、実行前の照合を、決裁済みの文書と公印を押した文書を受け取って使う側に組み込む。** 印影の真偽を見分けるのではなく、その承認が承認者本人の記録と結びつくかを、交付と使用の前に照合する。

### 注意したい業界・業務

- **業界 · 自治体・公的機関**: 紙の決裁と公印で契約や文書の効力を持たせる組織。共有フォルダに ID とパスワードだけで入れることが多い。
- **業務 · 承認・決裁**: 決裁文書の回付、公印の押印、契約書の交付。
- **業務 · データへのアクセス**: 共有フォルダと職員の個人専用フォルダ。

### いまの対策と Lemma の違い

今回の経路は 1 列目（他の職員の ID と端末の使用）と 2 列目（印影の偽造と公印の無断使用）の両方である。3 列目は、承認者本人が自分の権限で不正に決裁する場合で、今回そうだったという公表は無い。

| 対策 | 他の職員の ID・端末の使用 | 印影の偽造・公印の無断使用 | 承認者本人による不正な決裁 |
| --- | --- | --- | --- |
| ID とパスワードによる認証 | 効かない | 効かない | 効かない |
| 公印の施錠と使用簿 | 効かない | 一部 | 効かない |
| 印影の目視による確認 | 効かない | 一部 | 効かない |
| **Lemma（実行の前の照合）** | 効く | 効く | 効かない |

ID とパスワードは、知っていれば誰でも通り、端末の前にいる人を示さない（今回は他の職員の ID と端末が使われた）。公印の施錠と使用簿は、手続きを省いて押されると残らない（町は「事務手続きを怠り無断で」使われたとしている）。印影の目視は、紙から読み取って作られた偽造を見分けにくい。Lemma は、印影や ID ではなく、承認者本人の記録と、文書を使う前に照合する。

注：Lemma の照合が働くのは、決裁と押印を本人の鍵で署名した記録として残し、文書を使う手順に照合を組み込む場合に限る。承認者本人が不正に決裁する場合と、本人の鍵ごと渡っている場合は、この照合を通りうる。表は何を照合しているかの比較で、今回の事案で止まったかどうかを示すものではない。Lemma は、侵入や無断の立ち入りを検出・防止するものではなく、削除されたデータを戻すものでもない。

### 点検チェックリスト

決裁と共有フォルダについて、組織で確認する 3 項目

- 決裁済みの文書と公印を押した文書を、承認者本人の記録（誰が・いつ・どの端末で）と結びつけて使っているか。
- 共有フォルダと個人専用フォルダへのアクセスを、ID とパスワードだけでなく、本人の端末や多要素認証と結びつけているか。
- 勤務時間外の庁舎への立ち入りとフォルダへのアクセスを、記録して確認する手順があるか。

## 5. 事実と時系列

- **当事者**: 宮城県山元町（町長事務部局）。
- **起きたこと**: 町の公表によれば、町長事務部局の主事（26 歳）が、2026 年 6〜7 月に、勤務時間外に自身の端末から他の職員の ID とパスワードで庁内の共有フォルダに複数回アクセスし、データを閲覧・操作した。他の職員の端末も無断で使い、他の職員や自身の ID とパスワードで共有フォルダと個人専用フォルダに複数回アクセスし、データを閲覧・削除などした。7 月の他の職員の端末の件では、予め開錠していた庁舎 1 階の扉から深夜に入り、休日は休日勤務中の他の職員に扉を開錠させ、その職員が退庁した後に入った。また、事務手続きを怠り無断で公印（町長印）を使い、工事と業務委託の請負業者 2 社に公印を押した契約書を交付した。上司 2 名の印影を偽造し、うち 1 名の偽造した印影で未決裁の文書を決裁済みの文書として使った。印紙が貼られた書類から印紙の部分を読み取って加工する方法で印紙を偽造し、関係する業者から提出された書類を偽造して使った。
- **気づいた経緯**: 公表されていない。
- **影響と対応**: 町は、地方公務員法第 29 条第 1 項の第 1 号（法令等に従う義務の違反）、第 2 号（職務上の義務の違反）、第 3 号（全体の奉仕者にふさわしくない非行）に当たるとして、10 月 16 日付で免職とした。管理監督の責任で、課長級（56 歳）と班長（48 歳）を戒告とした。閲覧・削除されたデータの中身と、契約の相手・金額は公表されていない。

### 時系列

- **2026-06〜07**: 勤務時間外に、自身の端末から他の職員の ID とパスワードで共有フォルダに複数回アクセスし、データを閲覧・操作する。
- **2026-07**: 深夜と休日に庁舎へ入り、他の職員の端末を無断で使って、共有フォルダと個人専用フォルダのデータを閲覧・削除などする。
- **時期は公表されていない**: 公印の無断使用と契約書の交付、上司 2 名の印影の偽造、未決裁の文書の使用、印紙の偽造。
- **2026-10-16**: 町が、当該の職員を免職、課長級と班長を戒告とする。
- **2026-10-20**: 町が、公表基準に基づいて処分を公表する。町長が謝罪し、法令順守と綱紀粛正の徹底を図るとする。

> 本件の事実は、山元町の公表（一次・「山元町職員の懲戒処分等の公表（２件目）」）に拠る。公表は処分の理由として事実を記しており、データの中身、契約の相手と金額、発覚の経緯、警察への届出、再発防止の具体的な手立ては記していない。印影の偽造と公印の使用の時期も記されていない。同じ日に公表された 1 件目の処分は本件と別の事案である。公表されていないことは、対策が無かったことを意味しない。本 Brief は、町の対応や当該の職員を評価するものではない。

### 公表後の対応

- **山元町**: 町長は、2 件の不祥事を「町民への裏切り」として謝罪し、法令順守と綱紀粛正の徹底を図って信頼の回復に努めるとした。当該の職員の行為について、管理監督の責任で関係する職員も処分した。
