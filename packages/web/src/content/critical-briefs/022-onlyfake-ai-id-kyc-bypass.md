## 1. 要点

生成された画像は、本人確認でよく使われる撮り方の質感や、撮影の情報（EXIF）まで本物に似せてあり、受け付ける側には、本物の身分証を撮った画像と同じ形で届く。deepfake の検知や画像の解析は不正の試みの多くを止めているが、見分けるのは生成の痕跡で、作る技術との追いかけっこになる。<strong>身分証の画像がどれほど本物らしく見えても、発行元がその書類を発行したかは、画像の中身からは確認できない。</strong>

## 2. 通った操作

- **通った操作**: 暗号資産取引所 OKX の本人確認（KYC）への、OnlyFake で生成した英国パスポートの画像の提出。404 Media は、この画像で本人確認を通ったと報じた（2024-02-05）。
- **受け付けた側に届くもの**: 一般に、画像で受け付ける書類の確認に届くのは、身分証を写した画像と、その撮影の情報である。審査できるのは、書式に合っているか、質感や内容がそろっているかといった見た目で、発行元がその書類を発行したかは、画像には含まれない。
- **運営者の主張**: 匿名の運営者（自称 "John Wick"）は、大手の取引所や暗号資産を扱うネオバンクの本人確認を通せると主張し、「ニューラルネットワーク」で生成するとした。404 Media は、AI を使っているという主張そのものは確認できなかったとしている。
- **公表されていないこと**: 生成された画像で開かれた口座の数や、それが詐欺・資金洗浄に使われたか。OKX の審査が、どの段で画像を受け付けたか。

## 3. 実行前の照合

経路を問わず区別できる条件は、本人確認を受け付ける側が、提出された身分証を発行元が発行したかを、画像の見た目とは別に、口座を開く前に照合することである。

- **誰が承認を出すか**: 身分証の発行元（政府・発行機関）や、確認済みの ID の提供者。本人の属性に発行元が署名を付けて出し、受け付ける側はその署名を照合する。身分証を出す側が自分で名乗る形では出さない。
- **どこで照合するか**: 口座を開く手前。発行元の署名と、その書類が取り消されていないか・期限が切れていないかを照合する。照合できなければ、画像がどれほど本物らしくても、本人確認を通さない。受け付ける側が受け取るのは要件に要る属性（「18 歳以上」「制裁の対象でない」など）だけで、身分証の原本は受け取らない。
- **何が残るか**: どの属性を、どの発行元の署名で照合して口座を開いたかの記録。後から規制の報告や手続きで示せる形で残す。

検知は強まっている。ただ、生成の痕跡を探す検知は確率の判定で、見分けられなければ通り、口座が正当な本人確認を経て開かれたことを後から示す材料にはならない。顔の映像を仮想カメラで差し替える手口に、[eKYC の顔認証を破る道具の販売](https://lemma.frame00.com/ja/critical/briefs/034-ekyc-liveness-bypass/)がある。人の資格の属性が偽られた事案に[技術者の資格の偽り](https://lemma.frame00.com/ja/critical/briefs/019-construction-engineer-qualification-fraud/)、AI が作ったものの出どころでは [SynthID の透かしの解析](https://lemma.frame00.com/ja/critical/briefs/011-synthid-watermark-reverse-engineering/)が近い。

## 4. Lemma でできること

**Lemma は、実行前の照合を、本人確認を受け付ける側に組み込む。** 偽の画像を見つけるのではなく、本人の属性が発行元の署名付きで発行されたものかを、口座を開く前に照合し、要件に要る属性だけを受け取る。

### 注意したい業界・業務

- **業界 · 金融・FinTech**: 暗号資産取引所、暗号資産を扱うネオバンク、銀行など、オンラインで口座を開く事業者。本人確認を通った口座は、その後の取引や送金の前提として受け入れられる。
- **業務 · アカウント・権限の管理**: 口座の開設。身分証の画像と顔の映像が、本人の確認として使われる。

### いまの対策と Lemma の違い

今回の経路は 1 列目（身分証の画像の提出）である。2 列目は、WEF などが記した、顔の差し替えやカメラへの映像の差し込みで顔の確認を破る段で、今回そうだったかは公表されていない。

| 対策 | 身分証の画像の提出 | 顔の確認（自撮りの照合・ライブネス検査） |
| --- | --- | --- |
| 画像の見た目の審査（書式・質感・内容のそろい） | 効かない | 関係しない |
| 撮影の情報（EXIF）の確認 | 効かない | 関係しない |
| deepfake の検知・画像の解析・差し込みの検知 | 一部 | 一部 |
| **Lemma（実行の前の照合）** | 効く | 関係しない |

画像の見た目の審査は、生成した画像が本人確認でよく使われる撮り方の質感まで似せてあるので効かない。撮影の情報は、撮影した機器・日時・位置を書き換えられるので効かない。検知は、見分けられれば止まるが、作る技術との追いかけっこになる。Lemma は、画像の見た目ではなく、発行元の署名を、口座を開く前に照合する。顔の確認は Lemma の照合の外にある。

注：Lemma の照合が働くのは、発行元が本人の属性を署名付きで発行し、受け付ける仕組みにその照合を組み込んだ場合に限る。画像でしか受け付けない手続きは、照合の外に残る。本物の身分証や、本物のクレデンシャルを他人が使う場合は、署名の照合では見分けられない。表は何を照合しているかの比較で、今回の事案で止まったかどうかを示すものではない。Lemma は、侵入を検出・防止するものではない。

### 点検チェックリスト

オンラインで口座を開く事業者が、組織で確認する 3 項目

- 身分証の画像の撮影の情報（機器・日時・位置）を、本物である根拠として扱わない運用になっているか。
- 発行元の署名付きのデジタルクレデンシャルで、本人確認を受け付ける手段があるか。
- どの属性を何で照合して口座を開いたかを、後から示せる形で記録しているか。

## 5. 事実と時系列

- **サービス**: OnlyFake。身分証の画像を 1 通 15 ドルで生成する。米・加・英・豪・EU 各国を含む 26 か国の身分証に対応し、氏名・生年月日・住所・有効期限・署名を指定できる。本人確認でよく使われる「カーペットの上に置いて撮った」ような質感まで似せる（404 Media）。
- **撮影の情報**: 撮影した機器・日時・GPS の位置など、EXIF の書き換えにも対応するとされた（404 Media）。
- **確認されたこと**: 404 Media が、OnlyFake で生成した英国パスポートの画像で、OKX の本人確認を通ったと報じた。OECD.AI の事案の一覧にも載った。
- **運営者の主張**: 匿名の運営者（自称 "John Wick"）は、大手の取引所や暗号資産を扱うネオバンクの本人確認を通せると主張した。404 Media は、AI を使っているという主張そのものは確認できなかったとし、一方で価格の水準は自動の生成をうかがわせるとした。
- **受け付けた側の反応**: OKX は、特定の 1 社ではなく業界全体の問題だとの認識を示した（Benzinga / Nasdaq）。
- **被害**: 生成された画像で開かれた口座による、実際の被害の件数は公表されていない。

### 時系列

- **2024-02-05**: 404 Media が、OnlyFake の実証を報じる。OKX の本人確認を通ったとした。
- **2024-02-05**: OECD.AI の事案の一覧に載る。
- **2024-02**: 業界の各紙が追って報じる。OKX が、業界全体の問題との認識を示す。
- **2025**: 世界経済フォーラム（WEF）などが、AI で生成した書類・顔の差し替え・カメラへの映像の差し込みを組み合わせ、書類と顔の確認をともに破る攻撃の連鎖を記す。
- **2025**: 本人確認の業界の統計で、deepfake を使った不正の試みが 3 年間で 2,137% 増えたと報告される（Signicat）。
- **2025 上期**: deepfake に関わる詐欺の損失が、半年で約 4.1 億ドルに達したと報告される（AInvest の集約）。AML/KYC の違反への金融当局の制裁金も急増したとされる。

> 事実は 404 Media の報道と、OECD.AI の事案の一覧、Decrypt・Benzinga / Nasdaq の追報、業界の統計に拠る。本件は媒体による実証の報道で、生成された画像による実際の被害の特定の事案ではない。AI を使っているという主張は運営者のもので、404 Media はそれを確認できなかったとしている。公表されていないことは、対策が無かったことを意味しない。

### 公表後の対応

- **OKX**: 業界全体の問題との認識を示した。
- **本人確認の事業者**: deepfake の検知や差し込みの検知を強めている。一方で、生成と検知の追いかけっこは残ると報告している。
- **制度の動き**: EU の eIDAS 2.0 と EUDI Wallet に見られるように、発行元の署名付きのデジタルクレデンシャルと、要件に要る属性だけを示す開示を前提にした本人確認への移行が始まっている。
