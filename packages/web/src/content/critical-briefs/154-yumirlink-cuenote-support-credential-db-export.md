## 1. 要点

取られたのは、利用企業の担当者ではなく、運営会社の担当者の認証情報だった。攻撃者は、その認証情報で、ほかのシステムへの認証も試みていた（ユミルリンク）。認証が通ることと、その作業をしてよいことは、別のことである。<strong>運営会社の担当者の認証情報は、持っているだけで、どの利用企業のどの依頼の作業かが分からないまま、複数のシステムに開きうる。</strong>

## 2. 通った操作

- **通った操作**: 運営会社のサポート・品質管理担当者の認証情報での認証（ほかのシステムへの認証の試みを含む）と、不正なプログラムによるデータベースからのデータの出力（ユミルリンク）。
- **受け付けた側に届くもの**: 一般に、正しい認証情報での認証は、正規の担当者の操作として届く。その担当者が、どの利用企業のどの依頼で入ったかは、認証が通ったことからは区別できない。
- **公表されていないこと**: どのプログラムの脆弱性か、侵入が始まった日、担当者の人数と権限、多要素認証の有無。データの出力に担当者の認証情報が使われたか、ほかのシステムへの認証が成功したか。5 システムがどの利用企業のものか。重複を除いた人数。

## 3. 実行前の照合

経路を問わず区別できる条件は、運営会社の担当者が利用企業のシステムに入るとき、認証の通過とは別に、その作業が、どの利用企業のどの依頼に基づくかを、入る前に、利用企業の側にある依頼の記録と照合することである。

- **誰が承認を出すか**: 依頼を出す利用企業。作業の依頼を、問い合わせ番号などとともに利用企業の側で出し、期限を区切る。運営会社の担当者の側では作れない形で出す。
- **どこで照合するか**: 利用企業のシステムの認証・認可を受け付ける仕組み。依頼と結びつかない認証は、パスワードが正しくても通さない。通すときも、期限を区切る。
- **何が残るか**: どの依頼で、どの利用企業のシステムに、いつ入ったかの記録。運営会社の記録とは別に、利用企業が後から照合できる形で残す。

検知は働き、ユミルリンクはサーバを切り離し、ほかのシステムから担当者の情報を削除した。同じように、ベンダーの資格情報で顧客のテナントの操作が通った事案に、[ConnectWise のアプリ ID](https://lemma.frame00.com/ja/critical/briefs/069-connectwise-cloud-backup-app-identity-credential-abuse/) がある。069 はアプリが権限を変えた話で、こちらは人の担当者の認証が担当外のシステムへ広がろうとした話である。

## 4. Lemma でできること

**Lemma は、03 の照合を、運営会社の担当者が利用企業のシステムに入る側に組み込む。** 侵入を見つけるのではなく、届いた認証が、利用企業の依頼に基づくかを、入る前に照合する。

### 注意したい業界・業務

- **業界 · 自治体・公共**: 行政のお知らせや事業者向けのメールマガジンを、外部の配信サービスで送る自治体。委託先の会社が契約していると、配信先のリストがどこにあり、どのプランで動いているかが自治体から見えにくい。
- **業界 · 調達・サプライチェーン**: 会員や顧客へのメールマガジンを、配信の SaaS に預ける企業。配信のために、氏名や社内の識別番号まで連携していることがある。
- **業務 · アカウント・権限の管理**: 自社の配信環境に置かれた運営会社の担当者のアカウントと、管理画面・API の接続元の設定の管理。

### いまの対策と Lemma の違い

今回の経路は、1 列目（運営会社の担当者の認証情報での認証）と、2 列目（不正なプログラムによるデータベースの読み出し）の両方に関わるが、データの出力に認証情報が使われたかは公表されていない。3 列目は、利用企業の側の入口（管理画面と API の接続元）である。

| 対策 | 担当者の認証情報での認証 | データベースの直接の読み出し | 利用企業の側の入口 |
| --- | --- | --- | --- |
| 脆弱性の修正 | 効かない | 一部 | 関係しない |
| 利用企業の多要素認証 | 関係しない | 関係しない | 一部 |
| 管理画面と API の接続元の制限 | 一部 | 関係しない | 一部 |
| 不正アクセスの検知 | 一部 | 一部 | 一部 |
| **Lemma（実行の前の照合）** | 効く | 効かない | 関係しない |

脆弱性の修正は、入口をふさぐが、認証情報を持つ者に許される操作は変えない。利用企業の多要素認証は、取られたのが運営会社の担当者の認証情報だったため、今回の経路には関係しない。接続元の制限は、利用企業の側の入口を狭めるが、運営会社の担当者の認証まで止まるかは、公表からは分からない。検知は、アクセス記録の上で出力が起きた後に気づいた。

注：Lemma の照合が働くのは、利用企業のシステムの認証・認可を受け付ける仕組みに照合を組み込み、依頼の記録が運営会社とは別に管理されている場合に限る。サーバに不正なプログラムを置かれ、データベースを直接読まれた場合は、この照合を通らずに出力できる。今回の延べ約 900 万件の出力を、この仕組みで止められたとは言えない。担当している利用企業の依頼の範囲の中で悪用されれば通る。表は何を照合しているかの比較で、今回の事案で止まったかどうかを示すものではない。Lemma は、侵入を検出・防止するものではない。

### 点検チェックリスト

メール配信など、データを預ける SaaS について、組織で確認する 3 項目

- 管理画面と API の接続元を自社の IP アドレスに絞り、すべて許す設定のままにしていないか。
- 配信先のリストに、配信に要らない項目（氏名・業種・社内の識別番号など）まで入れていないか。
- 事故のときに、自社が影響を受けたかを運営会社から聞ける取り決めがあるか。

## 5. 事実と時系列

- **サービス**: Cuenote FC は、企業や自治体がメールマガジンや案内を一斉に送るためのメール配信サービス。影響があったのは、利用企業ごとに専用のシステムを用意する「専用 ASP プラン」のうち、ユミルリンクが管理する 5 システム（ユミルリンク）。
- **経路**: プログラムの脆弱性により、サポート・品質管理担当者のサービスへの認証情報を取得された。不正なプログラムを設置され、データベースからデータを出力された。担当者の認証情報を用いて、ほかのシステムへの認証も試みられた（ユミルリンク）。
- **出力された情報**: メールアドレスを含む情報、延べ約 900 万件（試算）。重複を除いた人数は公表されていない。利用企業や自治体の公表では、氏名、法人名、業種、システム内部の識別番号を挙げるものがある。
- **利用企業・自治体の公表**: 大日本印刷（honto）は、メールマガジンの配信を許諾した顧客の氏名、メールアドレス、識別番号が漏えいした可能性があるとの報告を受けた。埼玉県は、委託先の会社が使うメールマガジンで 669 者の情報が流出した可能性があるとした。NTTPC は、影響は確認できていないが可能性は否定できないとした。漏えいは確認されなかったと公表したところもある。
- **ユミルリンクの対応**: 不正アクセスを確認したサーバを直ちにネットワークから切り離し、脆弱性を直すプログラムを作って適用し、ほかのシステムから担当者の情報を削除した。捜査機関に届け出て、外部の専門家と詳しく調べている。サポートサイトでは、管理画面と API（システム連携の窓口）への接続元 IP アドレスの登録を必須にしたと案内している。

### 時系列

- **2026-10-16**: 未明、ユミルリンクの担当者が一部のシステムで不正アクセスを確認する。サーバを直ちにネットワークから切り離す。
- **2026-10-18**: 午後 2 時 15 分ごろから、山陽新聞社のメールによる速報などが配信できなくなる（山陽新聞社）。同社は翌日の第 2 報で、配信業務の委託先であるユミルリンクの件として知らせた。
- **2026-10-19**: ユミルリンクがサポートサイトで告知し、17 時 5 分に適時開示で第一報を出す。19 時 5 分、自社サイトの版に Cuenote FC と専用 ASP プラン 5 システムの記述を足す。
- **2026-10-20**: 埼玉県、NTTPC、各地の自治体などが、利用者への影響を公表する。山形県大江町は同日 11 時、流出は確認されなかったと追記する。
- **2026-10-21**: 大日本印刷が、honto の顧客情報が漏えいした可能性を公表する。

> 事実はユミルリンクの第一報と、利用企業・自治体の公表（いずれも一次）に拠る。ユミルリンクの第一報は、本文で「持ち出されたことを確認」と書き、見出しでは「漏洩した可能性のあるシステム」と書いている。第一報が「認証情報を用い」と書くのは、ほかのシステムへの認証の試みについてだけで、データの出力については「不正プログラムを設置し」と書いている。10 月 23 日時点で、第二報は出ていない。公表されていないことは、対策が無かったことを意味しない。

### 公表後の対応

- **ユミルリンク**: 脆弱性の修正、担当者の認証情報の削除、不正なプログラムを検知する体制の整備を再発防止策に挙げた。管理画面と API で、すべての接続元を許す設定は現時点では受け付けないとした。業績への影響は精査中。
- **利用企業・自治体**: 配信を止めて再開したところや、メール配信システムとの連携を切ったところがある。なりすましメールへの注意を呼びかけている。
