## 1. 要点

公開 API で技術的に取得できることと、規約が許す利用の範囲は、同じではない。研究チームは匿名化を施したと説明しているが、データセットは arXiv の論文とあわせて誰でも入手できる形で配布され、404 Media は、Discord の利用規約と開発者ポリシーに反すると報じた。報道は公開の後に働き、配布されたデータセットが下流へ渡る経路は、報道だけでは閉じない。<strong>集めた元の利用条件はデータセットの中身には残らないので、配布や学習の前に照合しない限り、規約が禁じる用途のデータも、ほかのデータと同じように下流へ渡る。</strong>

## 2. 通った操作

- **通った操作**: 公開 API による、公開サーバーのメッセージの一括取得と、arXiv の論文（2502.00627）・JSON のデータセットとしてのオンラインの公開。
- **受け付けた側に届くもの**: 一般に、公開 API は、問い合わせがどの用途のためかを区別せずに応答する。配布されたデータセットを受け取る側にも、匿名化が施されていても、集め方が規約の範囲だったかは、データセット単体からは分からない。
- **規約の定め**: Discord の開発者ポリシーは「API で取得されたメッセージの内容を機械学習または AI のトレーニング（大規模言語モデルを含む）に使用してはなりません」「Discord サービスにおいて、またはこれを介して、利用可能ないかなるデータ、コンテンツ、情報もマイニングまたはスクレイピングしてはなりません」と定める。利用規約にも、スクレイピングを禁じる条項がある。
- **研究チームの説明**: 配布の目的は、他の研究チームが「メンタルヘルスや政治について研究したり、ボットを訓練したりする際に使用できるようにするため」とし、ユーザー名の書き換えと、ID とメッセージのハッシュ化による切り捨てを施したと説明している。
- **公表されていないこと**: Discord の公式の声明（公開の時点では確認できない）。データセットが、下流で AI の学習に使われたか。

## 3. 実行前の照合

経路を問わず区別できる条件は、データを配布する前、またデータを学習に取り込む前に、そのデータが、どこから、どの利用条件で集められたかを、データの中身とは別に照合することである。

- **誰が承認を出すか**: データを配布する側。集めた元・集め方・利用条件（再配布や AI の学習への使用を認めるか）を、配布の前に示す。条件そのものは、集めた元のプラットフォームの規約に拠る。
- **どこで照合するか**: データセットを配布する手前と、受け取った側が学習に取り込む手前。自分の用途（例：機械学習）が、集めた条件に合うかを照合し、合わなければ配布せず、取り込まない。
- **何が残るか**: どのデータセットを、どの条件の照合を通して、どの用途に使ったかの記録。後から、学習データがどこから来たかを辿れる。

報道は、収集と公開の存在を示して論点を広げたが、データセットが arXiv に投稿され JSON として配布された後に働いた。受け取った側が、届いたものの出どころを照合しないまま扱う型の事案に、[Noroboto](https://lemma.frame00.com/ja/critical/briefs/005-noroboto-lying-fonts/)（AI が読む入力の偽装）がある。

## 4. Lemma でできること

**Lemma は、03 の照合を、データセットの配布と、学習への取り込みの手前に組み込む。** スクレイピングを見つけるのではなく、データがどこから、どの利用条件で集められたかを、配布や取り込みの前に照合する。

### 注意したい業界・業務

- **業界 · AI**: 学習データを外から集めて使う AI 企業と研究機関。公開されたデータセットは、下流の研究者や AI 企業が入手でき、学習データの来歴の説明（EU AI Act の学習データの文書化の要件など）が論点になる。
- **業務 · 情報の開示・提供**: データセットの公開・配布と、外部のデータセットの受け入れ。集めた元の規約と、配布・学習の用途が合うか。

### いまの対策と Lemma の違い

今回の経路は、1 列目（規約が禁じる用途のデータセットを配布する）である。2 列目は、受け取った側が学習に取り込む段で、今回そうなったかは公表されていない。

| 対策 | 規約が禁じる用途のデータセットを配布する | 受け取ったデータセットを学習に取り込む |
| --- | --- | --- |
| 利用規約・開発者ポリシーでの禁止 | 一部 | 一部 |
| 匿名化（ユーザー名の書き換え・ハッシュ化） | 関係しない | 関係しない |
| 報道・研究者による検出 | 一部 | 効かない |
| **Lemma（実行の前の照合）** | 一部 | 効く |

規約とポリシーは、禁じる用途を定めるが、公開 API の応答や配布の場で、その範囲かを照合する仕組みは伴わない。匿名化は、利用者の識別を減らすためのもので、集め方が規約の範囲かとは関わらない。報道と研究者の検出は、公開の後に存在を示すが、配布済みのデータセットが下流へ渡ることは止めない。Lemma は、配布する側と受け取る側の手前で、集めた元と利用条件を照合する。

注：Lemma の照合が働くのは、配布の場か、受け取る側が学習に取り込む手前に照合が組み込まれている場合に限る。配布する側が照合を使わずに公開した場合、配布の手前では止まらず、受け取る側の照合だけが残る。Lemma は、配布済みのデータを取り消したり、消したりするものではない。表は何を照合しているかの比較で、今回の事案で止まったかどうかを示すものではない。Lemma は、侵入を検出・防止するものではない。

### 点検チェックリスト

データセットの配布と受け入れについて、組織で確認する 3 項目

- データセットを公開・配布する前に、集めた元の規約が、再配布と AI の学習への使用を認めているかを確認しているか。
- 受け取るデータセットについて、集めた元と利用条件の記録を、データとは別に受け取っているか。
- どのデータセットを、どの条件で、どの学習に使ったかを記録し、後から辿れるか。

## 5. 事実と時系列

- **規模**: 20.52 億メッセージ（2,052,206,308）、3,167 サーバー、473 万 5,057 人、2015〜2024 年分。
- **対象の範囲**: Discord の「発見」機能で見つけた 31,673 の公開サーバーのうち、10% を無作為に選んだ（2024-11-17 時点）。
- **収集した主体**: ブラジルのミナス・ジェライス連邦大学の 15 名の研究者のチーム。
- **配布の形**: arXiv の論文（2502.00627）と、JSON のデータセットとしてオンラインで公開。
- **配布の目的**: メンタルヘルスや政治についての研究と、ボットの訓練に使える研究用のデータセット（研究チームの説明）。
- **匿名化**: ユーザー名の書き換えと、ID とメッセージのハッシュ化による切り捨て（研究チームの説明）。
- **規約の位置**: 404 Media は、Discord の開発者ポリシーの、機械学習・AI の学習への使用の禁止とスクレイピングの禁止、利用規約のスクレイピングの禁止に反すると報じた。
- **配布の範囲**: arXiv から誰でもダウンロードでき、下流の研究者や AI 企業へ渡る経路がある。
- **Discord の対応**: 公開の時点で、公式の声明は確認できない。同社は、2024-04 に、類似の事案 Spy Pet に対して法的措置を検討した経緯がある。

### 時系列

- **2015〜2024**: 収集の対象になったメッセージが、Discord の公開サーバーに蓄積されていた。
- **2024-11-17**: 研究チームが「発見」機能で 31,673 の公開サーバーを見つけ、10% を無作為に選ぶ。
- **2024-11-17 以降（推定）**: 公開 API で収集する。
- **2025-05**: arXiv の論文（2502.00627）と JSON のデータセットを公開する。
- **2025-05-22**: 404 Media が報じ、Discord の利用規約・開発者ポリシーに反すると指摘する。同日、日本語の媒体も続けて報じた。

> 本件は、攻撃による侵害ではなく、研究目的の収集と公開に関わる事案として扱う。事実は、404 Media の報道、研究チームの論文、Discord の開発者ポリシーに拠る。被害の規模は誇張しない。公表されていないことは、対策が無かったことを意味しない。

### 公表後の対応

- **404 Media**（2025-05-22）: 規約・ポリシーとの関係を示し、「研究者たちはデータを匿名化したと主張しているが、自分の Discord メッセージがオンライン上の公開ファイルに保存されていることを快く思う人はいない」「Discord ユーザーの多くは子どもであることに留意すべき」と論点を挙げた。
- **研究チーム**: 配布の目的を、他の研究チームの研究とボットの訓練のためとし、匿名化を施したと説明した。
- **Discord**: 公開の時点で、公式の声明は確認できない。過去には、Spy Pet（2024-04、6 億を超える Discord ユーザーを監視していた事業者）に対して法的措置を検討した。
- **業界の論点**: 生成 AI の企業が学習データの来歴を説明する責任（EU AI Act の学習データの文書化の要件、米 NIST AI RMF などのガイダンス）や、公開 API・規約・匿名化の主張が重なるときの、GDPR や各国のプライバシー法での位置づけが論点になった。
